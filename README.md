# Glass Tasks

Mobile-first task management web app for iOS Safari and desktop. White Liquid Glass-inspired UI, instant capture, swipe status, skeleton loading, Google OAuth-only sign-in, Cloudflare Workers/D1/Workers AI.

## Planned deployment

- Runtime: Cloudflare Workers (static assets + API)
- Database: Cloudflare D1
- AI: Workers AI
- Sign-in: Google OAuth 2.0

Production setup requires Cloudflare D1 database creation, Google OAuth credentials and session secrets. This repository currently contains the deployment plan; the app source has not yet been pushed. Production release and end-to-end browser verification are not complete.
